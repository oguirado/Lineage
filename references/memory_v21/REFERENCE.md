# Memory v2.1 public derivative

This is a Lineage derivative, not the full source paper or a memory kit implementation.
Original source digest and documentary statuses are unavailable and represented by null.

Mandatory per-agent memory and context-only inheritance follow NORTH_STAR.md P2–P4
and P8, and STRATEGY.md §2.2. An agent inherits constitution, skills, distilled lessons,
negative knowledge and promoted workflows as context, never model weights or raw episodes.
Level-one authority belongs only to the operator. Only receipt-backed level-two context
is inheritable; level-three observations and foreign-project rulings are not inherited.

Lineage's fail-closed run_close requires a valid same-agent memory write after run_open.
This enforced closing gate is a Lineage adaptation of the unfulfilled enforcement target
in Memory v2.1 §6.1.1, not a claim that the paper implemented enforcement.

Memory v2.1 §3.7 concerns storage latency; it does not establish correctness credit.
Memory v2.1 §6.1.1 reports 0.718 versus the older reference's 0.738 [CITED:
STRATEGY.md §0.2; NORTH_STAR.md §6]. The memory variant did not beat that reference,
and a written lesson did not change behaviour. Inherited memory benefit remains unproven.
Measure whether inherited memory helps through arms with and without inherited memory;
never assume improvement. Selection requires a declared credit rule before benchmarking.
