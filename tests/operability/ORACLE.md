# U27 fail-first oracle

Status: **PARTIAL — instrument assertions frozen; live and external acceptance evidence AUSENTE — no inventar.**

Only test files and public-interface Python stubs are authored in this flight.
`docs/OPERABILITY.md` is unchanged. No application, wire schema, UI source,

The JSON schemas are required by tests but are not replaced with fake schemas.

## Execution and evidence boundaries

Run from the repository root:

```sh
python3 -m unittest discover -s tests/operability -t .
```

Unexpected `NotImplementedError("U27 stub")` must remain an ERROR. The rejection
helper rethrows it explicitly; it is never credited as a valid refusal. Missing
imports, invalid fixtures, syntax errors and unrelated assertions do not qualify
as the intended fail-first result. Every executed test must reach a specified
public callable; optional observers are recorded separately as unexecuted.

The default suite performs no network access, downloads, real browser/native
launch or real sleeps. The pipe specimen is an offline Python child with command
and response descriptors `3/4` [TARGET], NUL framing, interleaved events and
fragmentation. It uses short explicit deadlines [TARGET], not a fixed sleep as a
success witness. Every process cleanup acts on a recorded Popen child whose PID
is greater than `1` [TARGET]. There are no process-group operations. Test scratch
files are disposable subdirectories of `tests/operability`, as required by the
flight's write boundary. No shared browser profile is used.

`RealBrowserTests` is opt-in through caller-supplied `U27_BROWSER` and
`U27_SELFTEST_ORIGIN`. The caller prepares a disposable loopback origin serving
the frozen pages; default discovery neither creates that server nor contacts it.
Configured runs must execute their positive and hostile assertions. Their scope
stays `selftest`, never `fixture` or `live`. Skips carry an explicit INCONCLUSIVE
reason. A skipped native/browser/capsule/persona gate provides no W5/W6/W7/W8
acceptance. No live receipts or persona scores are reported here.

## Specimen and instrument distinctions

`good.html` and `inventory-good.json` define an explicit synthetic Agents
context, with full persisted identities, native controls, shell semantics and
known empty revision. They do not replace application fixtures or a seeded live
home. `article-control.html`, `duplicate-names.html`, `overlong-name.html`,
`clickable-div.html`, `positional-selector.html`, `stale-ready.html` and
`missing-witness.html` are rejecting contrasts. `inventory-positional.json`
keeps the expected identity while substituting a positional selector.

The synthetic native trees are public AT-SPI interface fakes. The clean-room
transform receives independently authored canonical forests. Neither is a
receipt from a real native session. The DOM fixture parser checks specimen
integrity only; it does not supply accessible names or a C/A result. Metadata
shape tests do not establish artifact existence, authenticity or hash equality.
Postcondition witnesses are synthetic wire specimens, not live journal receipts.

Methods C/A/P/V and scopes selftest/fixture/live remain separate. Source absence,
missing native exposure, missing fixtures, absent external definitions and
incomplete cleanup cannot become PASS. No source vocabulary is deleted to make
a partial context appear complete. The full acceptance oracle remains incomplete
until the BLOCKED definitions and environments above are supplied.
