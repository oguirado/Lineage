## Isolation and discrimination

The supplied `lineage/core/registry.py` and `lineage/core/app.py` use the extracted seed API; K0 `Context`, `Services`, `ToolSpec`, `LineageError` and `lineage/core/schema.py` are unavailable. `_support.load_surface` temporarily supplies the documented K0 seam in memory and restores the import environment. It never edits a provider or asserts real U04/domain integration. HTTP children receive their own isolated modules and registry. Handler invocation counts, asserted actor/authority/transport, synthetic committed-prefix counters and fixture-file snapshots are adapter witnesses only. Synthetic event objects are not journal-verification receipts.

`RunningServer` reports a child `NotImplementedError("U06 stub")` back to the test unchanged, so red startup is not misreported as an import error or readiness timeout. A running implementation must pass actual HTTP assertions; no test catches its own expected assertion failure as product success. Request sockets target only an owned loopback listener. There is no external network, package installation, fixed sleep, process-group operation or unowned signal. Deadline guards and bounded pipe/socket/event/process waits constrain each test. Shutdown targets only the verified child PID. Stalled-body tests observe a finite accepted-socket timeout and accelerate that timeout inside the child, avoiding a new product timeout requirement.

## Decisions and limits

- Frozen K0 wins over proposed `CallContext`, `DispatchResult`, `mutating` and `lineage.serve.http.main`. Both returned errors and raised `LineageError` are tested. The production adapter is never given a compatibility fallback.
- `resolve_asset` receives URL paths with a leading slash; `/` denotes the index. Symlinks at the static root or below are refused, while symlinked ancestors are permitted. Descriptor-safe opening is observed using an `os.open` swap, not a private helper name.
- Index query rejection versus ignoring was explicitly left open. Tests accept either `400 bad_args` or unchanged bootstrap `200`, and require no dataset/head/clock switch. API health/tools queries are rejected. An unsupported HEAD checks the error status/headers while respecting HTTP's body suppression.
- Text MIME types, SVG and JSON require UTF-8; binary PNG/WOFF2 bytes remain unchanged. Existing markup is preserved except reserved session meta tags.
- Fixture tests use an empty dataset rather than inventing source reference pins, agent/run records or nonempty campaign history. JSON collection wrappers beyond manifest, response entries and scenario metadata are not fully specified; the helper uses empty arrays and an empty per-agent memory map. That narrow fixture-shape assumption must be reconciled with the owning fixture unit before integrated acceptance. Inconsistent declared head may be refused as configuration `bad_args` or integrity `hash_mismatch`; neither refusal is treated as successful admission.
- Actual fixture payloads, source-reference artifacts, browser observers and the publication checker interface remain **AUSENTE — no inventar**. No real fixture, UI, source repository or domain provider is edited. No spy or synthetic prefix is reported as authoritative journal proof.
