# U21 fail-first oracle

This suite is frozen against `.unit/SPEC.md`, including Amendment B, `docs/CONTRACT.md`, `docs/OPERABILITY.md` and the supplied North Star. All paths are relative to the repository root. Test-case identifiers are references, not measurement claims.

## Assertion boundary

The supplied tree has no `ui/` implementation. `helpers.ts` checks required source/data availability with an assertion before dynamically importing it. It provides transport doubles, deferred promises and DOM scaffolding, never production stubs or substitute implementations. Missing source fails with `Required U21 deliverable … is absent`; it does not become a module-resolution failure. Behavioral assertions following that gate remain unexecuted until the deliverable exists. A red availability assertion establishes the missing prerequisite, not that every deeper assertion has already been exercised.

Tests use injected transports and fetch doubles, bounded microtask drains and virtual timeout advancement. No test makes a real network call, downloads dependencies, starts a server, uses a real sleep, creates process groups or sends process signals. The only test subprocess is the installed TypeScript CLI with `--showConfig`, bounded below the per-test deadline. Test deadlines are 4000 ms [TARGET]. Module loading, fixture data and source inspection use only the assigned tree and supplied packages.

The targeted verification command is `cd ui && ../node_modules/.bin/vitest run tests/shell --cache=false --maxWorkers=1`. Cache disabling prevents writes to dependency/tool cache directories; the worker limit only bounds execution resources. No generated log or private receipt is stored. Build/typecheck host checks are separate: tests never run a build that writes outside their assigned directory. There are no skipped, todo or expected-failure tests.

## Contract decisions

- Amendment B changes discovery to `{tools: ToolDescriptor[]}` and the session header to `X-Lineage-Session`. The previous `X-Lineage-Session-Token` header is explicitly rejected as the active header.
- `docs/OPERABILITY.md` wins the presentation conflicts, as SPEC_U21 explicitly directs: `Application updates`, `Unknown page. Showing Agents.`, `{Screen} navigation` names, native `theme-light` / `theme-dark` buttons, `retry-panel`, and benchmark detail `data-lin-screen="bench"`. The shared TypeScript registry still has the specified five module ids; benchmark detail uses the `arena` module and its `benchId`. Honest not-built content remains mandatory. Tests do not invent a sixth module or domain features.
- K0's `#/agents`, `#/agents/<agent_id>`, `#/lineage`, `#/arena`, `#/arena/<bench_id>` and `#/ledger` routes remain authoritative. Benchmark syntax uses K0 `Id`, `[A-Za-z0-9_-]{8,64}`. Empty hash, `#` and `#/` canonicalize to Agents; trailing slashes are rejected. This resolves the explicit Amendment B routing choice. Valid syntax does not prove record existence.
- K0 ignores unknown route query keys with a notice; dangerous prototype keys and duplicate keys reject the route. This supersedes the pre-K0 proposal to retain unknown keys. Canonical query tests use declared keys only.
- The router factory is callback-first, `createRouter(onChange, initialHash?)`, per Amendment B. Hash history is replayed with deterministic native notifications; actual browser Back/Forward remains an external confirmation.
- The fixed mutation/export/external set enumerates actual K0 effectful tools. `agent_get`, `agent_list`, `agent_brief` and `run_get` remain reads; wildcard wording does not turn these public reads into mutations. Dishonest `mutation:false` rejects before fetch, fixture writes always yield `fixture_readonly`, and `agent:"operator"` cannot acquire UI authority.
- Primitives enforce individual name validity/byte limits. Cross-control normalized-name collisions belong to `lintOperability`, not a hidden global registry in each primitive. Full identity attributes survive punctuation and reordering. No token-name spelling or palette is prescribed by the tests.
- Screen replacement must abort the outgoing context before disposal. Focus restoration uses the amended optional announcement callback. Dialog tests exercise jsdom fallback behavior without claiming native modal proof.
- The event fold tests use K0-shaped records. The supplied `schemas/event.schema.json` requires `op_id` and `evidence`; Amendment B's conditional reference to K0 optionality does not justify assuming optional fields against that schema. These tests assert transport structure and cursor behavior, never client hash-chain authority.
- Browser bootstrap may report invalid fixture configuration by a `TransportError` with `invalid_config` or a visible `invalid_config` state. Either path must avoid live fallback. Public store/router/shell factories are wrapped only to dispose automatic bootstrap resources; no private entry function is required.
- A resync must be visible while the replacement read is pending. Message storage is not prescribed because AppState does not specify a notice field; store tests check restart/clearing, and shell tests observe rendered text.
- CSS tests calculate sRGB contrast from actual emitted CSS and resolve custom properties and alpha compositing; unresolved colors fail. Their role inventory is tied to rendered presentations. This is DOM/CSS evidence only, not browser geometry or native accessibility certification. System-theme and reduced-motion browser observations remain external where K0's controls supersede the draft selector.
